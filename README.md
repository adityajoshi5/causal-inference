# causal-inference

Supporting material for a foundational tutorial on causal inference.

## Course notebooks

The repository includes a starter notebook structure inspired by the Coursera course [*A Crash Course in Causality: Inferring Causal Effects from Observational Data*](https://www.coursera.org/learn/crash-course-in-causality).

- `notebooks/week-01-introduction-to-causal-effects/week-01-introduction-to-causal-effects.ipynb`
- `notebooks/week-02-confounding-and-dags/week-02-confounding-and-dags.ipynb`
- `notebooks/week-03-matching-and-propensity-scores/week-03-matching-and-propensity-scores.ipynb`
- `notebooks/week-04-iptw/week-04-iptw.ipynb`
- `notebooks/week-05-instrumental-variables/week-05-instrumental-variables.ipynb`

Each notebook contains a basic outline with learning goals, module topics, notes, and exercise sections that can be expanded into full lesson materials.
